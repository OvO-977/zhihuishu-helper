# 智慧树助手（zhihuishu-helper）

一个用于智慧树（Zhihuishu）课程页面的视频播放辅助 Tampermonkey 用户脚本。

脚本会在课程视频页面提供一个右下角悬浮控制面板，用于切换播放倍速、自动续播当前视频，并在当前视频完成后继续播放下一个视频。

## 功能

- 支持 `1x`、`1.25x`、`1.5x`、`3x` 播放倍速切换。
- 自动保存上一次选择的播放倍速，下次进入页面后继续使用。
- 视频意外暂停时，延迟 2 秒后自动尝试继续播放。
- 当前视频播放结束后，延迟 2 秒自动尝试播放下一个视频。
- 当前视频已播到末尾但目录进度仍未达到 `100%` 时，自动从头重新播放当前视频，避免因为倍速播放导致进度未刷满而卡住。
- 支持通过悬浮面板手动跳转到下一个视频。

## 使用环境

本脚本主要在以下环境中开发和测试：

- 操作系统：Windows 11
- 浏览器：Microsoft Edge
- 脚本管理器：Tampermonkey
- 适用页面：智慧树课程视频播放相关页面

智慧树页面结构可能会随平台更新而变化，不同课程、账号或页面版本下的表现也可能不同。

## 安装

1. 在浏览器中安装 Tampermonkey 扩展。
2. 打开 Tampermonkey 管理面板。
3. 新建用户脚本。
4. 将 `zhihuishu-helper.user.js` 中的代码复制到脚本编辑器中。
5. 保存脚本。
6. 打开智慧树课程视频页面，脚本会在匹配页面自动运行。

## 使用

进入智慧树课程视频页面后，页面右下角会出现一个悬浮按钮。

点击悬浮按钮可以打开控制面板：

- 选择播放倍速。
- 手动切换到下一个视频。
- 触发当前视频继续播放。

脚本会在后台处理以下播放流程：

- 如果视频暂停且尚未播放完成，会尝试自动续播。
- 如果视频结束且目录进度已完成，会尝试切换到下一个视频。
- 如果视频结束但目录进度未满 `100%`，会优先重新播放当前视频。

如果浏览器或平台限制自动播放，可能需要先手动点击一次页面或视频播放器，之后脚本才能正常接管播放。

## 实现依赖

脚本依赖智慧树页面中的部分 DOM 结构和页面函数，包括：

- `video`
- `.file-item`
- `.folder-item`
- `.icon-video`
- `.file-item.active`
- `.status-box .rate`
- `.status-box .icon-finish`
- `window.changeFile`

如果平台调整了页面结构、样式类名或切换视频的方式，脚本可能需要同步调整。
